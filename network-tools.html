Network Utilities

Build and preview network commands before you run them.

A console for the commands you reach for mid-incident: diagnostics, DNS/routing lookups, and API request builders. Fill in a target, pick your flags, and get the exact syntax plus a formatted preview of what the output looks like.

This is a static, client-side page — it builds correct command syntax live, but the console output is illustrative/simulated (browsers can't open raw sockets or spawn shell processes). Wire the "Run" actions to your own backend or agent to execute for real.
